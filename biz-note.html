❓ 사업자 관리 노트

파트너의 성장을 코칭하고 거위를 살찌우는 도구입니다.
1️⃣ 기본 사용법
👤 파트너 등록
이름 입력 → 추가 버튼 / 레그·핀레벨·관계발달·분기목표·월간목표 설정 후 저장
🎯 목표관리 탭
1~4주차 탭에서 카탈/장스오/STP 목표·실적 입력 → 월간목표 탭에서 주간 합산 확인
🔥 실행관리 탭
파트너 Needs → 진행 내용(제안·코칭·소통) → 파트너 반응 → 다음 약속 → 피드백 순서로 기록 (코칭·소통 통합)
2️⃣ 코칭 단계
지식공유 → 지식인지 → 지혜활용 → 변화(도전)
지식공유: 카탈/장스오/STP 지식 나눔
지식인지: 파트너가 이해하고 인지
지혜활용: 파트너가 현장에서 직접 활용
변화(도전): 파트너 스스로 변화·도전·복제
3️⃣ 3% 필수 액션
카탈로그·장스오·STP 중 해당 액션을 모두 선택하세요. (중복 선택 가능 ✅)
